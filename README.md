# Explanation-Augmented Multi-Agent Consensus (EXCRE)

Codebase for MSc dissertation: Explainability-Augmented Cross-Model Reasoning Exchange.

## Overview

Investigating multi-agent consensus mechanisms among heterogeneous large language models using structured reasoning exchange and consensus scoring.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
